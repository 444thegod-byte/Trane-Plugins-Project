# 面板 logo 资产的来源与处理

## 这是什么

`trane_logo.bin` —— 面板顶栏右上角那枚金属徽标（准星 + 12 星环 + 左下熔滴），
**透明底**，用来替代 v0.35 及以前画在左上角的 `Trane` 标题与 `41 CONTROLS` 副标题。

## 处理

由 `tools/make_logo_asset.py` 从源图**完全可复现地**生成：

```
python3 tools/make_logo_asset.py                  # 重建 trane_logo.bin
python3 tools/make_logo_asset.py --check          # 校验磁盘上的资产与重建结果逐像素一致
python3 tools/make_logo_asset.py --preview p.png  # 另外导一张 PNG 供人看
```

四步：

1. **抠底 —— 按亮度映射 alpha，不是洪水填充。**
   `alpha = clamp((248 − min(R,G,B)) / (248 − 214), 0, 1)`。
   背景是纯白（四角实测 255,255,255；`min ≥ 252` 占 84.78%），金属是冷灰，
   用 `min` 通道判"白"最保守。
   *为什么不用洪水填充：* 中心圆环**内部**与左下熔滴**内部**是两块封闭白区，
   从边界走不到，洪水填充会原样留下（合到黑底上是一圈白盘，实测占 5.0%）。
   亮度映射的判据是"这个像素白不白"，与连通性无关 —— 同一指标降到 **0.01%**。
2. **反锯齿** —— alpha 上做一次 `GaussianBlur(0.6)`。只碰 alpha，不碰 RGB，
   免得把背景白抹进边缘。
3. **色调提升** —— `out = 255 × (in/255)^0.70`，逐通道。
   面板顶栏那块底色是**纯黑**，原图金属在纯黑上平均亮度只有 81.2，熔滴基本糊掉。
   用 gamma 曲线而不是乘系数：暗部抬得多、亮部抬得少，高光不爆。
   实测金属实体平均亮度 81.2 → **107.7**，90 分位 124.5 → 158.8。
   （同轮用户要求里就有"所有文字亮度调高"，这条与之同向。）
4. **裁包围盒 + 缩到 384 高** → **375 × 384**。
   面板上画 96 逻辑 px（2× 屏 = 192 设备 px），384 留了 2 倍余量，
   且 384 / 192 = 2 是整数倍降采样。

## 落盘格式：自制容器 `TRNL`，不是 PNG

和 `assets/video/backdrop.bin` 同一条理由：**面板层不许出现 `ImageFileFormat`
/ `loadFrom`** —— `tests/test_editor_layout.py` 的
`test_panel_layer_never_touches_the_filesystem` 盯着这一条，它是"面板层的输入
完整地只有一个 `PanelState`"那条架构约束的护栏。为了一张静态图去把护栏改松
不划算；烤成裸像素之后运行时只是一次 memcpy，比 PNG 解码还快。

小端布局：

| 偏移 | 长度 | 内容 |
|---|---|---|
| 0 | 4 | magic `TRNL` |
| 4 | u32 | 版本号，当前 1 |
| 8 | u32 | 宽（375） |
| 12 | u32 | 高（384） |
| 16 | w×h×4 | 像素，逐行，**BGRA** 字节序 |

**BGRA 不是 RGBA** —— 这是 JUCE `PixelARGB` 在小端机上的内存布局，
直接 memcpy 进 `juce::Image` 就是这个顺序（本工程只出 arm64 / x86_64 两种
小端目标）。脚本每次运行都会把容器解回来与原始像素逐字节比对。

## 量化自检（脚本每次都会打印）

| 指标 | 值 | 说明 |
|---|---|---|
| `alpha = 0` | 74.0 % | 背景 |
| `alpha` 中间 | 15.8 % | 反锯齿边 |
| `alpha = 255` | 10.3 % | 金属实体 |
| 不透明但接近纯白 | **0.01 %** | 洪水填充那版是 5.0 %；硬门槛 0.5 % |
| 金属实体平均亮度 | 107.7 | 提升前 81.2 |

## 进二进制的方式

和字体、背景动画一样走 `juce_add_binary_data`（见 `vst/CMakeLists.txt` 的
`TraneAssets`），**不运行时读文件** —— 插件装到哪儿都一样。

绘制侧的几何常量（尺寸、落位）在 `plugin/TranePanel.h` 里，与其它面板几何同源。
