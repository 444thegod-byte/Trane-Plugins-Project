# Träne Plug-ins Project

> 用于实验电子音乐制作与现场演出的**实时解构效果器**。
> 硬边切片、磁带停转、谐振染色、波形折叠。

**当前版本：v0.36** ｜ 格式：VST3 + AU + Standalone ｜ 通用二进制（`arm64` + `x86_64`）

> **📖 使用说明（面向使用者）见 [`docs/使用说明.md`](docs/使用说明.md)** ——
> 安装、界面导读、操作方式、十个模块逐个详解、实用配方、排错、参数速查表。
> 本文件（README）讲的是**工程**：为什么这么设计、怎么构建、怎么验证。

## 一、这个项目是什么

Träne 是一个音频效果器插件，把输入音频捕获进缓冲区，然后可以无限冻结、粒子化成雾、
再逐级解构（切片重触发 → 谐振梳状 → 磁带变速 → 波形折叠 → 扫频 → 延迟 → 超大空间），
最后经过前瞻限制器输出。

它**不是**一个"综合效果器大礼包"，而是一条有明确顺序的解构链。顺序本身就是设计：

```
capture → freeze → grain → STUTTER → COMB → TAPE → ruin → sweep → delay → space → limiter
```

| 环节 | 作用 | 为什么在这个位置 |
|---|---|---|
| **freeze** | 把最近的输入变成无缝无限循环 | 解构的素材来源；不跟随 BPM，循环长度就是抓取区间长度 |
| **grain** | 带窗的重叠颗粒，把素材变成雾 | 提供"厚"的底子 |
| **STUTTER** | 硬边切片原地重触发 | 放在粒子之后：切的是"已经成雾的东西"，得到碎但厚。只做粒子会糊，只做切片会干 |
| **COMB** | 谐振梳状滤波，染上音高感 | 放在磁带之前：让谐振跟着磁带一起被拉慢，音高一起掉才像真的 |
| **TAPE** | 变速 + 磁带停转 + wow/flutter | 有限长度磁带机的物理行为，见下文 |
| **ruin** | 环形调制 → tanh 饱和 → **波形折叠** → 位深压碎 | 折叠在压碎之前：先折出谐波，再压位深把谐波糊开 |
| **sweep** | 随机扫频谐振滤波器 | 选随机而不是 LFO —— LFO 有周期感，随机没有 |
| **delay** | 阻尼延迟，可 ping-pong | |
| **space** | 超大空间混响 | |
| **limiter** | 前瞻峰值限制器 | 折叠和反馈都会爆电平，必须兜住 |

## 二、工程结构

```
vst/                      主工程（VST3 / JUCE）
├── core/                 DSP 核心。**刻意不依赖 JUCE**，可独立编译与离线渲染
├── probe/                离线测量台，一个模块一个 main()
├── plugin/               JUCE 外壳（Processor + Editor），很薄，只做接线
├── assets/               打包进二进制的素材（字体、面板品牌标）
├── tests/                pytest，解析探针输出并断言
├── tools/                面板预览渲染、素材生成、反向对照等辅助脚本
├── external/JUCE/        第三方依赖（不进仓库，用 setup_juce.sh 拉取）
├── CMakeLists.txt
├── run_tests.sh          一键验证：构建 → pytest → 像素检查 → 反向对照 → 端到端
└── setup_juce.sh         拉取精确版本的 JUCE

docs/                     面向使用者的文档（使用说明）
src/                      Max for Live 版本（**已非主路线**，保留备查）
tools/                    M4L 构建工具
tests/                    M4L 静态验证
outputs/                  面板预览、对照图、安装包
.workbuddy-ai/            项目记忆与配套技能
```

### 为什么 core 不依赖 JUCE

这是整个工程的硬性设计。只有 DSP 能**脱离宿主独立编译与离线渲染**，才谈得上
毫秒级迭代、自动化断言、数学检验。一旦 core 里出现 `#include <juce_*>`，
验证就只能靠"开 DAW 听"，这条路就废了。

### 为什么放弃 Max for Live

Max/MSP 依赖 iLok + Java，**无法在自动化环境启动**，只能静态验证接线。
代价是真实的：曾经一个功能连错两轮都没发现（根因是把 message 接进了 `record~`
的音频信号输入口）。VST3 能编译、能离线渲染、能用数学方法检验输出 ——
**可验证性**才是选它的真正理由，不是性能。

## 三、构建与验证

### 环境要求

- macOS + Xcode 命令行工具（`xcode-select --install`）
- CMake ≥ 3.22、Ninja
- Python 3，且装了 `numpy` 与 `soundfile`

### 步骤

```bash
git clone <this-repo>
cd Trane-Plugins-Project/vst

./setup_juce.sh          # 拉取 JUCE 9.0.2（精确 commit，见脚本内注释）

./run_tests.sh           # 构建 + 全部测试 + 端到端验收
./run_tests.sh --quick   # 只跑测试，跳过构建
```

`run_tests.sh` 会**自动探测** Python / cmake / ninja，换机器不用改文件。
探测 Python 时会真的去 `import numpy, soundfile` 试一次 —— 只看版本号不够，
有些 Python 装好了但没装这两个库，按版本挑会挑中它然后在测试阶段才炸。
要强制指定某个解释器，用环境变量：

```bash
TRANE_PY=/path/to/python3 ./run_tests.sh
```

依赖缺失时脚本会直接报出缺什么、怎么装，不会跑到一半才失败。

旧 M4L 补丁的静态检查用 `python3 tools/verify_patch.py`。macOS 默认只查
`/Applications` 与 `~/Applications` 直属的 `Ableton Live*.app`，按安装包版本选择最新的 Live；
同版本按完整路径字典顺序选择，输出实际使用的 Max 资源目录。
要检查指定的运行时，或在其他系统运行，设置唯一覆盖项
`MAX_RESOURCES="/真实路径/Max.app/Contents/Resources"` 后执行同一命令。
指定路径无效、对象清单缺失或数据库为空都会报告环境错误并退出，不会当成补丁对象缺失。

> **注意**：构建的后处理步骤会把插件装到 `~/Library/Audio/Plug-Ins/{VST3,Components}/`，
> 覆盖本机已安装的同名插件。所以在任何克隆目录里构建，都会影响你当前装着的那个。

### 验收门槛

**构建 → pytest 127 项 → 面板像素检查 → 六组反向对照 → 端到端验收**，必须全过。

`run_tests.sh` 用 `set -euo pipefail`：任何一步失败就停在那里，
所以"跑到最后一行"本身就说明前面每一段都过了。

**反向对照（变异测试）**是这套门禁里最要紧的一段。做法是**故意把源码改坏**、
重编、确认检查器**真的报红**，然后还原。绿本身不是证据 ——
一个永远绿的检查器什么都没检查。六组对照共 **34 处突变**，全部必须被抓到。

端到端验收这一步和前面的测试性质不同：它不是测 DSP 源码，而是把编译出来的
`.vst3` 真的当插件加载起来、通过 VST3 参数接口设参数、渲染音频、再分析结果。
它证明的是"**这个文件能装进 DAW 干活**"，而不只是"算法写对了"。

产物安装到 `~/Library/Audio/Plug-Ins/{VST3,Components}/`。
打安装包用 `./tools/make_installers.sh <版本号>`（版本号必须与 `CMakeLists.txt` 一致，
脚本会自己校验）。

## 四、几个不显然但重要的实现约定

这些都是踩过坑之后定下来的，改之前先看 `.workbuddy-ai/memory/MEMORY.md`。

### 1. 停转必须同时停住写头

Tape 模块的缓冲区是有限的（8 秒）。如果只停读头、写头照常前进，
8 秒后写头会绕回来**覆盖读头正在读的位置**，停转就自己"复活"了。
真磁带停住时读到的是**不变的静态磁化** —— 模拟它就必须冻结写头。

实测证据：修复前停转末段 RMS 是 0.174（应该为 0）；修复后停转 20 秒仍精确为 0。

### 2. 调制不能乘在推进速率上

`pos += speed * (1 + wob)` 会把抖动**积分**成无界的位置漂移，撞到缓冲区边界后
被夹住，抖动就被削成"只往一边摆"。

正确做法是拆成两个量：`posAbs`（匀速位置，参与缓冲区存量计算）
+ `wobOffset`（有界 LFO 位移，上限 3ms）。

### 3. 前瞻限制器必须带前瞻

反馈式限制器对瞬态必然过冲（实测 +4.8 dB 时峰值 1.0062）。
前瞻 2ms + 单调队列最小增益，数学上不可能过冲。

代价是 2ms 延迟 → 必须 `setLatencySamples()`，并且**必须自己实现 `processBlockBypassed`**
（JUCE 基类版本假定延迟为 0，会把干声往前推）。

### 4. 参数显示名必须唯一

宿主按名字查找参数只认第一个。曾经三个参数都叫 `Size`、三个都叫 `Rate`，
结果是端到端验收里按名字找不到参数，**整段解构链验收静默跳过，最后还打印"通过"**。
现在有静态回归测试盯着显示名唯一性。内部 ID 可以随便改，显示名不行。

### 5. 随机数必须固定种子

粒子与扫频的随机数用固定种子的 xorshift32。否则渲染不可复现，无法做回归测试。

## 五、界面规范

目标：**模块化效果器那一挂的克制版本** —— 平面、无装饰、信息密度高，
参照物是硬件面板（一块面板上的控件形态是**这块面板的设计语言**，不是逐个参数挑出来的）。

- 纯黑底；**只有黑白两色**，层次靠不透明度。四态（正常 / 悬停 / 按下 / 焦点）
  **只改颜色，不改几何**。
- 字体 = **打包进二进制的 Inter 静态实例**（`assets/fonts/TraneSans_*.ttf`，OFL-1.1，
  经 `createSystemTypefaceFor` 建成 Typeface）。早前那版运行时读 Ableton Live 里的
  `AbletonSans-*.otf`，**已彻底删除**，源码里不许再出现 Ableton 字体路径 ——
  依赖用户机器上装了什么字体，等于把渲染结果交给运气。
- 旋钮 = 实心平面盘 + 1px 环 + 指针 + 起/中/止三刻度。
  **禁止**值弧、渐变、阴影、卡片。
- 分组靠**框**不靠留白：每模块一个容器（块底 + 发丝框线 + 圆角 10）。
- **面板上不许有任何非交互文字** —— 没有产品名、没有功能介绍、没有版本号、
  没有运行状态。（唯一例外：顶栏右上角的品牌标，那是**图形**不是文字。）
- 面板 **1440 × 720**（比例锁死 2:1），缩放范围 60% – 150%。
- **48 个控件**（41 个连续参数 + 7 个模块开关）分布在 **10 个模块 / 4 栏**里。
  控件形态**按模块**分配：前五个模块（FREEZE / GRAIN / STUTTER / COMB / TAPE）整块旋钮，
  后五个（RUIN / SWEEP / DELAY / SPACE / OUT）条形 —— 判据是"这个模块是**调**出来的
  还是**配**出来的"。

界面规范详见 `.impeccable.md`；排版与视觉有一整套静态回归测试盯着
（`vst/tests/test_editor_layout.py` + `vst/tests/test_ui_design.py`），
包括"每个参数都必须挂了界面控件"—— 这条防的是"某个模块根本没有面板和旋钮"
这类编译期和 DSP 测试都发现不了的问题。

**文字对比度是可测量的**：面板把所有"文字 × 底色"对登记在 `textLog()` 里，
`--dump-text` 吐出来，测试用 WCAG 公式**独立复算**每一对（当前最暗 5.06:1，
是选中分段块上的白字压在 Apple 语义色 `#636366` 上，已经满档）。

**面板层不碰文件系统**：`TranePanel` 不依赖 `juce_audio_processors`、
不读文件，只接收一个 `PanelState`。所有 IO 归 `PluginEditor`。
这条护栏让 `panel_probe` 能用**和插件完全相同的绘制代码**离线渲 PNG ——
不是另画一套预览。

## 七、现状与未完成

**已完成并量化验证**（下表全部来自离线段探针，每个数字都有对照组）：

| 模块 | 关键实测 |
|---|---|
| Freeze 无缝循环 | 6 种循环长度（20–1000 ms）自相关 **0.999993 ~ 1.000295**，周期误差 **0**，与源录音内容相关 **1.000000** |
| Stutter 切片 | 切片长度处自相关 **0.9223**（对照组 0.0022，差 400 倍） |
| Tape 变速 | speed 0.25/0.5/1.0 → **250.00 / 500.00 / 1000.00 Hz** 精确命中 |
| Tape 停转 | 20 秒后末段 RMS 精确 **0.00000000** |
| Comb 定音 | tune 110/220/440 → **109.84 / 220.18 / 440.37 Hz** |
| Wavefold 谐波 | 谐波含量 **1.3023**，纯 tanh 饱和仅 0.3754（3.5 倍） |

> **别把两个来源的数字混着看。** 端到端验收（把真实 `.vst3` 加载起来跑）里
> Freeze 的自相关是 **0.9325**，明显低于上表的 0.9999 —— 因为那条路径上
> `Space Mix = 1`，混响混在信号里本身就会去相关，不是 Freeze 变差了。
> 上表测的是 DSP 本身，端到端测的是"整条链装进 DAW 之后还能不能工作"，
> 两者回答的不是同一个问题。

**未完成**：

- Pitch 独立于 Rate 的高质量变调（现在 rate 改读速，音高与速度耦合）
- Freeze 的 Hold Mode（Static / Drift / Scan）与 Release 淡出
- Scene / 预设系统、8 个 Macro、MIDI 映射
- Intel 真机实测（通用二进制已备好）
- **在 Ableton Live 里实际听 v0.36** —— 最关键的一步

### v0.36 改了什么（2026-09-30）

- **顶栏换标**：删掉 `Trane` 与 `41 CONTROLS` 两行文字，换成用户的金属 logo
  （右上角，右缘对齐参数区右缘 1400，偏差 0.00px）。
  logo 从源图**按亮度映射 alpha** 抠成透明底（不是洪水填充 —— 中心圆环内部与
  熔滴内部是**封闭白区**，洪水填充走不到，会留白盘：实测 5.0% 不透明近白，
  改判据后降到 **0.01%**），再做 gamma 0.70 提亮（金属实体平均亮度 81.2 → 107.7）。
  素材落成**自制裸像素容器**（`TRNL`，375×384）而不是 PNG ——
  面板层有"不碰文件系统"的护栏，为一张静态图把护栏改松不划算，
  而且裸像素运行时只是一次 memcpy，比 PNG 解码还快。
- **全部文字提亮**：`kAMuted 0.60 → 0.72`、`kAOff 0.56 → 0.64`、
  `kAHoverName 0.80 → 0.88`。块上最暗对比度 **5.36 → 7.03:1**（WCAG 独立复算）。
- **新增第七组反向对照** `tools/check_logo_mutations.py`（4 处突变全中）。
