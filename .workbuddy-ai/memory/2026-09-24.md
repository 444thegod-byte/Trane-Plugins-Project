## 重大转向：推翻 Max for Live，改做 VST3（v0.7）

**触发**：用户反馈 Freeze 完全无效（"开启 freeze 会一直响、不会断、无限循环、不跟随 tempo，loop 时间就是 loop 区间的长短"），并要求删掉 ARP。用户随后授权："实在不行，直接推翻 max for live，直接做 vst3 也没毛病"。

**Freeze 无效的直接根因（已定位，写在这里备查）**：
- `obj-9`(message "0") 与 `obj-132`(message "1") 都接到了 `record~` 的**入口 0**，而入口 0 是**音频信号入口**。message 送进信号入口会把该入口的输入覆盖成常数 —— 录音缓冲区里录进去的全是静音/直流。`plugin~` 也接同一入口，三个源争抢。
- 这类错误只要能在本地跑一次就一秒钟可见。**这正是 M4L 路线的死结**：Max 依赖 iLok + Java，本机无法运行，只能静态验证接线，所以连错两轮都发现不了。

**转向的技术理由（不是性能，是可验证性）**：
- M4L 简单是因为"借"（借用官方 DSP 对象 + Live 原生控件 + 自动参数系统），代价是**我看不见结果**，每一轮都只能"我改 → 他测 → 他说明 → 我猜"。
- VST3 难在要自己写 DSP/UI/参数系统，但**我能编译、能离线渲染音频、能用频谱与包络分析**。这是质变。
- 用户没有额外损失：`.amxd` 他本来也改不了，两边都是我在改。
- M4L 已定稿的设计（面板、参数范围、粒子架构、板式混响）**全部可移植**，不算白费。

**环境事实**：clang 17 + Command Line Tools 已装；cmake / ninja 用 pip 装到隔离环境 `/Users/444_thegod/.workbuddy-ai/binaries/python/envs/default/`（同环境还有 numpy / scipy / soundfile / pytest）。**pytest 必须加 `--basetemp=.pytest_tmp -p no:cacheprovider`**，否则沙箱下默认临时目录会 PermissionError。

**已完成并验证的 DSP 核心（`vst/core/`）**：
- `CaptureBuffer` — 8 秒环形持续采集，整数读（循环用）+ 线性插值读（粒子变速用）。冻结时写头停住，保护正在循环的区域不被覆盖。
- `FreezeLoop` — **无缝无限循环**。核心算法：循环区间 `[S, S+L)`，在末尾 seam 个样本里把**循环起点之前**的真实音频淡进来，于是环绕那一瞬的输出是 `buf[S-1] → buf[S]`，而这两点在原始录音里本就连续，数学上不存在跳变。全程零 tempo 概念。
- `GrainCloud` — 64 声部粒子云，参数集借鉴 Lux Cache 的 petri/concatenative（"grain length, spread, density" + "per-hit dice: pan, pitch, start, reverse each take an amount"）。随机数用固定种子 xorshift → **渲染可复现**，否则测试无法断言。
- `PlateReverb` — Freeverb 拓扑，8 并联梳状 + 4 级串联全通；两处针对"非常大"的改动：延迟线可放大 2.5 倍 + 梳状加低频调制（不加则长尾金属鸣响）。
- `Ruin` — Clear/Ruin 连续人格：环形调制 → 饱和 → 位深压碎。
- `TraneEngine` — 总装：capture → freeze → grain → ruin → reverb → limiter。粒子取材区间随冻结状态切换。

**量化验证结果（这是转向的核心收益）**：
- Freeze：周期误差 **0** 样本；lag=L 处自相关 **0.999993**；与源录音内容相关 **1.000000**；静音窗口 **0/392**；接缝跳变 0.0058（干声 0.0407）。
- **反证**：接缝淡化关掉（0ms）→ 接缝跳变 **0.266936**，是信号自然跳变的 6.5 倍（明显咔哒）；开 2ms 即降到 0.008691。证明接缝算法在起真实作用，不是装饰。

- 粒子引擎电平与理论值吻合：实测/理论 = **0.851**，而线性插值对白噪声的理论衰减正是 `sqrt(2/3)=0.816`。

**本轮修掉的自身错误（都靠离线探针当场发现）**：
1. `PlateReverb::setParams()` 只赋值没重算系数 → tail/size/damp 全部不生效（四个 tail 值给出完全相同的 RT60）。
2. 粒子归一化漏补汉宁窗 RMS 损失 → 一开粒子平白掉 10dB。
3. 分析器自身的两个 bug：自相关没做重叠归一化（把 `1 - L/N = 0.9363` 误判成"循环不成立"）；内容比对没做相位对齐。
4. 测试里用中文引号嵌进 C 字符串导致截断（**这个坑踩过两次了，写 C 字符串里的中文务必用「」**）。
5. `const float* src[2]` 无法传给 `float* const*` 形参。

**测试门槛**：`vst/tests/` 共 **30 项**全过（`test_freeze_dsp.py` 18 项 + `test_engine_dsp.py` 12 项）。

### 本轮修掉的问题
1. **验收程序硬编码假设**：写死"归一化 0.35 = 250ms"，但参数带 skew，实际是 79.83ms
   → 拿错周期去算自相关，把正确的循环误判成失败（自相关只有 0.41）。
   改成**回读参数真实值** `lp->getText(lp->getValue(), 32).getFloatValue()`。修好后 0.9325。
2. **限制器对瞬态过冲（真实缺陷）**：原来是"先量峰值再降增益"的反馈式，起控 1ms。
   峰值到达那一刻包络才刚开始爬，增益还是 1.0 → 必然过冲。实测 +4.8dB 输出增益下峰值冲到 **1.0062**。
   → 重写为 `LookaheadLimiter`（前瞻 2ms + 单调队列维护窗口内最小增益）。
   数学上不可能过冲：输出位置 i = t+L 处，窗口 [t, t+L] 含 gT[t] = thr/|x[t]|，
   而 gSmooth ≤ gMin ≤ gT[t] → y[i] ≤ thr。修好后峰值精确 **0.950000**。
   → 同时 `setLatencySamples()` 上报 2ms。
3. **旁通延迟不一致（真实缺陷）**：JUCE 基类 `processBlockBypassed` 假定延迟为 0
   （源码里还有 `jassert(getLatencySamples() == 0)`），本设备报了 2ms →
   旁通时干声会被往前推 2ms。→ 自己实现 `processBlockBypassed`，
   走一遍限制器的延迟线但 `enabled=false`。
4. **`parse_kv` 正则被骗**：`=== engine_probe ===` 这行把 "engine" 开头的 'e'
   当成数值（因为 e 是科学计数法字符）。→ 名字部分禁止含 '='，数值改严格形式。
5. **排版测试空转通过**：分组坐标第三参数写的是 `kLabelY[n]` 而不是数字，
   正则匹配不到 → 循环体一次都没执行，测试"绿了"但什么都没测。
   → 修正则解出 kLabelY，并加 `assert len(groups) >= 5` 兜底。

## 一、四个新 DSP 模块（全部量化验证过）

信号链改为：`capture → freeze → grain → STUTTER → COMB → TAPE → ruin(ring→tanh→FOLD→crush)

### `core/Stutter.h` —— 硬边切片重触发
自有 1 秒环形缓冲（**不复用粒子缓冲，粒子带窗会毁掉硬边**）+ 触发闩锁 + 切片循环。
`sizeMs 90 / rateHz 4 / jump 0.35 / mix 1.0`。两端 0.3ms 淡化只为去直流冲击。
淡化长度必须 `min(declick_, sliceLen_/2)`，否则两条淡化曲线互相吃掉。
固定种子 xorshift32（`0x6D2B79F5u`）。
**实测**：lag=切片长度自相关 **0.9223**，对照组 0.0022（差 400 倍）；size 60/100/200ms 命中倍数 1.00。

### `core/Tape.h` —— 有限长度磁带机
8 秒缓冲 = 磁带总长。`posAbs_`（匀速，参与存量计算）+ `wobOffset_`（有界 LFO，上限 3ms）。
**实测**：speed 0.25/0.5/1.0 → 250.00/500.00/1000.00Hz 精确命中；
wobble=0.8 → ±4.00% 而存量恒 514 样本（证明无漂移）；
**攒带子再加速**：0.25x 跑一段再切 2.0x → 1948.57Hz；无存量直接切 2.0x → 停在 1000.00Hz。

### `core/Comb.h` —— 谐振梳状
`D = sr/tune`，分数延迟线性插值；右声道延迟 **×1.008**（比例错开做宽度）；
反馈路径隔直 + 阻尼低通，`dampCoef = 0.30 + 0.45*(fb/0.95)`。
**实测**：tune 110/220/440 → 109.84/220.18/440.37Hz；自相关@周期 fb=0.4/0.7/0.9
→ 0.1935/0.4475/0.6966（单调，对照组 0.0013）。

### `core/Ruin.h` 加 FOLD
三角折叠 `f(x) = 1 - |t - 1|`，`t = x - 4*floor((x+1)/4)`，周期 4、输出恒在 [-1,1]。
`foldGain = 1 + foldAmt*8`，**干湿混合保证 fold=0 时逐位一致**。
**实测**：fold 0.0/0.3/0.6 → 总谐波 0.0073/0.1342/1.3023，纯 tanh 饱和只有 0.3754（**3.5 倍**）。
