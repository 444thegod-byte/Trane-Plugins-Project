## 一、这是什么

Träne 是一个**实时解构效果器**。它把输入音频抓进缓冲区，然后可以无限冻结、
粒子化成雾、再逐级拆开——硬边切片、谐振染色、磁带停转、波形折叠、扫频、延迟、
巨大空间。

它**不是**"什么都有"的综合效果器，而是一条**有固定顺序的解构链**。
顺序本身就是设计，不是随便排的（见[第六章](#六信号链)）。

**它适合什么**：解构俱乐部、实验电子、氛围/噪音、把一段干净素材变成不可辨认的东西。
**它不适合什么**：当"标准混音工具"用。它是一个**声音设计工具**，不是 EQ/压缩器。

### 一个重要的事实：出厂状态不是"全干"

面板上有 **7 个模块带开关**（FREEZE / GRAIN / STUTTER / COMB / TAPE / SWEEP / DELAY），
它们出厂时**全部关闭**。

但 **RUIN 与 SPACE 没有开关**——它们永远在链路上：

| 模块 | 出厂值 | 意味着 |
|---|---|---|
| RUIN | Mode = 0（Clear）、Drive = 0.35 | 出厂就带一点温和饱和，不是完全透明 |
| SPACE | Mix = 0.55、Size = 0.7、Tail = 0.8 | 出厂就有一层明显的空间感 |

**想要完全干净**：把 `Space Mix` 拧到 0、`Ruin Drive` 拧到 0。
**这是有意的**：这两个模块是"底色"，不是"效果"；给它们开关反而会让人以为
"关掉 = 干净"，而实际上关掉的只是它们内部的分支。

## 二、安装与卸载

### 2.1 三个安装包的区别

安装包在 `outputs/Trane_v0.36_Installers/`：

| 文件 | 内容 | 适合 |
|---|---|---|
| **`Trane-Plugins-v0.36.pkg`** | VST3 + AU 一起装 | **推荐**。双击下一步到底 |
| `Trane-VST3-v0.36.zip` | 只有 `Trane.vst3` | 想手动摆放 / 便携安装 |
| `Trane-AU-v0.36.zip` | 只有 `Trane.component` | 只用 Logic / GarageBand |
| `Trane-Standalone-v0.36.zip` | `Trane.app` | 不开 DAW，想直接试听 |

### 2.2 用 pkg 安装（推荐）

双击 `Trane-Plugins-v0.36.pkg`，一路继续即可。

它会装到**用户级**目录，**不需要管理员密码**：

```
~/Library/Audio/Plug-Ins/VST3/Trane.vst3
~/Library/Audio/Plug-Ins/Components/Trane.component
```

> **为什么不装到 `/Library/Audio/Plug-Ins/`（系统级）？**
> macOS 会**同时扫描**用户级与系统级两个目录。如果两边各有一份、版本还不一样，
> 你会遇到最难查的那类问题——"我明明装了新版，怎么还是旧界面"。
> 用户级只有一份，不会打架。这个坑真踩过。

如果 macOS 提示"无法打开，因为来自身份不明的开发者"：

```
右键点击 pkg → 打开 → 在弹窗里再点一次「打开」
```

（首次运行需要这样确认一次，之后就正常了。也可以在
「系统设置 → 隐私与安全性」里点「仍要打开」。）

### 2.3 用 zip 手动安装

解压后把 `Trane.vst3` 拖到 `~/Library/Audio/Plug-Ins/VST3/`，
把 `Trane.component` 拖到 `~/Library/Audio/Plug-Ins/Components/`。
目录不存在就自己建一个。

Standalone 的 `Trane.app` 拖到「应用程序」里就能双击运行。

### 2.4 在 DAW 里让它出现

装完要**让 DAW 重新扫描插件**：

| DAW | 怎么做 |
|---|---|
| **Ableton Live** | 设置 → Plug-Ins → 把「使用 VST3 系统文件夹」等选项关掉再打开，或点「重新扫描」 |
| **Logic Pro** | 一般会自动扫描。不行就重启 Logic |
| **Reaper** | 选项 → 首选项 → Plug-ins → VST → 「重新扫描」 |
| **Studio One / Cubase** | 插件管理器 → 重新扫描 |

**新建一个音频轨道**，在效果器列表里搜 `Trane`。

### 2.5 卸载

删掉这两个（或三个）即可，没有别的东西留在系统里：

```bash
rm -rf ~/Library/Audio/Plug-Ins/VST3/Trane.vst3
rm -rf ~/Library/Audio/Plug-Ins/Components/Trane.component
rm -rf /Applications/Trane.app
```

插件**不写任何配置文件到系统目录**。预设保存在工程文件里，跟着工程走。

## 三、五分钟上手

### 第一步：听到"冻结"

1. 建一条音频轨，**放一段有节奏的循环**，让它播着。
2. 挂上 Träne。
3. 点一下 **FREEZE** 这个模块标题（点标题就是开关）。
4. 现在声音被钉成了一段无限循环。拧 **`loop`**（20–2000 ms）改循环长度——
   短了是嗡嗡的持续音，长了是一小段反复的乐句。

> **冻结不跟随 BPM。** `loop` 是毫秒，不是拍。这是有意的：
> 它要的是"抓住刚才那一下"，而不是"跟上这首歌"。

### 第二步：把它切碎

5. 点开 **STUTTER**，把 `rate` 拧到 4–12 Hz。声音开始被硬边切片反复。
6. 拧 `size`（切片长度）和 `jump`（跳多远）。`jump = 0` 是最紧的原地重复，
   `jump` 大了会跳到缓冲深处，变成碎片拼贴。

### 第三步：把它拉慢、拉停

7. 点开 **TAPE**。
8. 把 `speed` 从 1.0 往下拧。音高会跟着掉（这是磁带的物理行为，不是变调器）。
9. 拧到 **0**——磁带停转，声音定死在一个点上。**它可以无限保持，不会自己复活。**

### 第四步：染色

10. 点开 **COMB**，把 `tune` 拧到 110–440 Hz 附近。
    声音会突然"有音高"了——这是谐振梳状滤波，不是加了个音。
11. 点开 **RUIN** 那边的 `fold`（波形折叠）。声音开始长出不存在的泛音。

到这里你已经把这台机器的主要部分都摸过一遍了。

## 四、界面导读

### 4.1 尺寸

面板逻辑尺寸是 **1440 × 720**（比例锁死 **2:1**）。
打开时按显示器大小自动缩放，范围 **60% – 150%**。

### 4.2 顶栏

从左到右：

| 位置 | 内容 | 说明 |
|---|---|---|
| 左 | **`CHOOSE IMAGE`** 格 | 点一下选背景图。选过之后显示文件名 |
| 中 | **`OFF` / `FULL`** 两格 | 背景图落位：关掉 / 铺满参数区 |
| 中右 | **明暗度轨道 + 读数** | 0.25× – 4.0×，几何级数。点哪儿跳哪儿，也可以拖 |
| **右** | **金属 logo** | 品牌标，纯装饰，点它没反应 |

### 4.3 参数区：四栏十模块

参数区是**四栏**。阅读顺序（从左到右、从上到下）**就是信号顺序**：

```
┌──────────┬───────────┬──────────┬─────────────┐
│  FREEZE  │  STUTTER  │   RUIN   │    DELAY    │
│  GRAIN   │   COMB    │  SWEEP   │    SPACE    │
│          │   TAPE    │          │     OUT     │
└──────────┴───────────┴──────────┴─────────────┘
  12 行       13 行        12 行        14 行
```

每个模块是一个**圆角容器**：一层浅底色 + 一圈发丝框线。
分组靠"框"，不靠留白——所以模块之间不会看起来像散落的参数。

### 4.4 两种控件形态

十个模块按**形态**分成两组，这不是随便定的：

| 形态 | 模块 | 判据 |
|---|---|---|
| **旋钮**（整块都是旋钮） | FREEZE · GRAIN · STUTTER · COMB · TAPE | 这些是"**调**"出来的：你要反复拧、听、再拧。参数之间**不可比**（冻多久 / 粒子多细 / 切多快 / 音高多少 / 带速多少） |
| **条形**（横向轨道） | RUIN · SWEEP · DELAY · SPACE · OUT | 这些是"**配**"出来的：你在看几个份量的**比例**，参数在同一把 0–1 尺上、互相可比 |

一句话：**前五个是信号链的"形"，后五个是信号链的"量"。**

> **为什么模块内的形态是统一的？** 因为一块 Eurorack 面板上的控件形态是
> **这块面板的设计语言**，不是逐个参数挑出来的。同一模块里混着旋钮和条形，
> 看起来就像两个不同的东西被塞进一个框。

### 4.5 视觉语言

- **纯黑底**，只有黑白两色，层次全靠不透明度。
- 模块框：底色 + 框线，圆角 10px。
- 旋钮：实心盘 + 一圈环 + 指针 + 起/中/止三刻度。**没有值弧、没有渐变、没有阴影。**
- 参数行：`参数名 ····· 轨道 ····· 数值`。数值是**右对齐**的，宽度按"最宽的那个数"统一预留——
  所以四栏的轨道起点在同一条竖直线上，不会跟着栏跳。
- **四态**：正常 / 悬停 / 按下 / 键盘焦点。悬停是 160ms 的淡入，不是"啪"一下。
- 关闭的模块，它的参数行是**压暗**的，但**照样可以拖**——你可以先把参数调好再打开模块。

## 五、操作方式

### 5.1 改一个数值

| 操作 | 效果 |
|---|---|
| **按住往上拖** | 变大。满量程 = 纵向 **200 像素** |
| **按住往下拖** | 变小 |
| **按住 + `Shift` 拖** | **精调**，满量程 = 1000 像素（慢 5 倍） |
| **按住 + `⌘` / `Ctrl` 拖** | **极精调**，满量程 = 4000 像素（慢 20 倍） |
| **滚轮** | 一步 1/200 量程。按住 `Shift` 滚 = 1/1000 |
| **双击** | **复位到出厂值** |
| **单击** | 连续参数**不改值**（防手抖碰歪）。分段参数（`LP / BP / HP`）切下一档 |

拖动是从**按下的那个值**算绝对偏移的，不是从上一帧累加——
所以快速甩动也不会丢事件、不会跳。

### 5.2 开关模块

**点模块标题行 = 开/关这个模块。**

七个模块有开关：**FREEZE · GRAIN · STUTTER · COMB · TAPE · SWEEP · DELAY**。

**RUIN / SPACE / OUT 的标题行点不动**——它们没有开关，面板也**不画**状态方块。
（不假装有开关。）

### 5.3 双击的两种含义

| 双击哪里 | 做什么 |
|---|---|
| 参数行 / 旋钮 | 这一个参数复位到出厂值 |
| **模块标题行** | **这个模块里所有连续参数**一起复位 |

> 开关参数（模块的 on/off）**故意不复位**。
> 因为双击会先送出两次单击，两次单击已经把开关来回切了一遍；
> 如果双击再把开关复位成"关"，净效果就是"**这个开关点不开**"。

### 5.4 键盘

| 键 | 做什么 |
|---|---|
| `Tab` / `↓` | 焦点移到下一个参数 |
| `Shift+Tab` / `↑` | 上一个 |
| `←` `→` | 改值（1/100 量程）。在 `LP/BP/HP` 上是切档 |
| `Return` | 切换焦点所在**模块**的开关 |
| `Esc` | 取消焦点 |

> **空格故意没有绑定。** 在 Ableton 里空格是播放/停止，插件抢走它每次都会被骂。

### 5.5 参数自动化

在 DAW 里挂自动化时，**拖动的整个过程算一次编辑**（手势在按下时开、松手时关）。
所以不会因为拖了 200 个鼠标事件就往自动化里塞 200 个点。

## 六、信号链

```
输入
 │
 ├─► ① FREEZE    抓取 8 秒；冻住 → 把最近 loop 毫秒钉成无限无缝循环
 ├─► ② GRAIN     带窗的重叠粒子云，把素材化成雾
 ├─► ③ STUTTER   硬边切片，原地重触发
 ├─► ④ COMB      谐振梳状滤波，染上音高
 ├─► ⑤ TAPE      变速 / wow-flutter / 停转
 ├─► ⑥ RUIN      Clear ↔ Ruin：环形调制 → 饱和 → 波形折叠 → 位深压碎
 ├─► ⑦ SWEEP     随机扫频谐振滤波器（LP / BP / HP）
 ├─► ⑧ DELAY     阻尼延迟，可 ping-pong
 ├─► ⑨ SPACE     巨大板式混响
 ├─► ⑩ OUT       输出增益 → 前瞻限制器
 │
输出
```

### 为什么是这个顺序

顺序不是随便排的，每一处都有理由：

| 环节 | 为什么在这个位置 |
|---|---|
| **FREEZE 最前** | 它是**素材来源**。后面所有东西处理的都是它抓下来的那段 |
| **GRAIN 在 STUTTER 之前** | 切的是"已经成雾的东西"，得到**碎但厚**。只做粒子会糊，只做切片会干 |
| **COMB 在 TAPE 之前** | 让谐振**跟着磁带一起被拉慢**——音高一起掉才像真的磁带。反过来就成了"慢放 + 独立滤波"，一听就假 |
| **TAPE 在解构链最后** | 停转要把**整条谐振一起拽下去**。如果 TAPE 在 COMB 前面，停转时 COMB 还在按原音高共振 |
| **RUIN 在 SWEEP 之前** | 先折出谐波，再让扫频去**选**这些谐波。反过来扫频只会扫到还没被破坏的信号 |
| **DELAY 在 SPACE 之前** | 延迟的重复声也要吃到混响，否则回声听起来像贴在混响外面 |
| **限制器最后** | 折叠和反馈都会爆电平，必须兜住 |

## 七、十个模块逐个详解

下面每个模块给一张参数表。表里 **`短名`** 是面板上显示的名字（空间紧张，用了缩写）。

---

### 7.1 ① FREEZE — 冻结

**作用**：把输入音频抓进缓冲区，然后把"最近的 N 毫秒"钉成一段**无限无缝循环**。

这是整台机器的**素材来源**。没有冻结，后面所有模块都只是在处理普通输入。

**它不跟随 BPM。** `loop` 的单位是毫秒，不是拍。这是刻意的设计。

| 短名 | 宿主名 | 范围 | 默认 | 说明 |
|---|---|---|---|---|
| — | **Freeze** | 开/关 | **关** | 模块开关（点标题行） |
| `loop` | Loop | 20 – 2000 ms | **250** | 循环长度。20ms 是嗡嗡的持续音，2000ms 是一小段完整乐句 |
| `seam` | Seam | 0 – 40 ms | **10** | 接缝交叉淡化长度 |

#### 为什么它真的"无缝"

循环的最后一小段里，会**把循环起点之前的真实音频淡进来**。
于是环绕那一瞬间的输出是 `buf[S-1] → buf[S]`——而这两个点在原始录音里
本来就是连续的。**数学上不存在跳变**，不是"淡化掩盖了咔哒"。

`seam = 0` 就不做淡化，会有咔哒——这个设置在某些 Ruin 用法里反而有用。

> 实测：6 种循环长度（20–1000 ms）的自相关在 **0.999993 – 1.000295**，
> 周期误差 **0**。

#### 冻结中改 `loop` 会怎样

会做一次**很短的凹陷**，避免咔哒。不会"啪"一下换长度。

---

### 7.2 ② GRAIN — 粒子云

**作用**：从采集缓冲区里撒出一片**带窗的重叠颗粒**，把素材化成雾。

和 STUTTER 完全不同：**粒子云是带窗的（平滑、成雾），切片是硬边的（有棱角、有断口）。**
两个叠在一起才是那种"碎但厚"的质感。

| 短名 | 宿主名 | 范围 | 默认 | 说明 |
|---|---|---|---|---|
| — | **Grain** | 开/关 | **关** | 模块开关 |
| `size` | Grain Size | 5 – 500 ms | **120** | 单个粒子的长度 |
| `dens` | Grain Density | 0.5 – 100 gr/s | **12** | 每秒撒几个粒子 |
| `rate` | Grain Rate | 0.25 – 4.0 × | **1.0** | 粒子播放速率。**同时决定音高与时长**（慢放 = 变长 + 变低） |
| `pos` | Grain Position | 0 – 1 | **0.5** | 在取材区间里的位置。0 = 最旧，1 = 最新 |
| `spry` | Grain Spray | 0 – 1 | **0.15** | 位置随机量。大了每个粒子起点都不同 |
| `sprd` | Grain Spread | 0 – 1 | **0.6** | **声场**随机量（每个粒子随机摆到左右） |
| `rev` | Grain Reverse | 0 – 1 | **0.25** | 反向播放的概率 |
| `mix` | Grain Mix | 0 – 1 | **1.0** | 干声 ↔ 粒子云 |

**怎么调**：

- 想要**雾**：`size` 大（200–400ms）+ `dens` 高（30+）+ `spry` 高。
- 想要**颗粒感**：`size` 小（10–40ms）+ `dens` 低（3–8）。
- 想要**打击感的碎片**：`size` 小 + `dens` 高 + `rev` 拉高。
- **冻结着用效果最好**：冻结之后 `pos` 就变成了"在那一小段循环里挑位置"。

> **取材区间会自动跟着 FREEZE 走。** 冻结时，粒子只在冻结窗口内取；
> 没冻结时，取最近 4 秒。

> **每个粒子的音高有 0.15 的固定随机量**（面板上没有这个旋钮）。
> 这是为了不让所有粒子听起来是同一个音——它是"消除缺陷"，不是创作参数。

---

### 7.3 ③ STUTTER — 切片重触发

**作用**：抓住刚刚过去的一小段声音，**原地反复重放**。切得硬、切得碎。

这是解构俱乐部音乐里**最标志性的一招**。

**做法**：自带一个最长 1 秒的环形缓冲，一直写。
每 `1/rate` 秒触发一次：从写头往回 `size + 随机跳位` 处**闩住**一段切片，
然后以 1× 速率循环播放它，直到下一次触发。

| 短名 | 宿主名 | 范围 | 默认 | 说明 |
|---|---|---|---|---|
| — | **Stutter** | 开/关 | **关** | 模块开关 |
| `size` | Stutter Size | 5 – 500 ms | **90** | 切片长度 |
| `rate` | Stutter Rate | 0.25 – 30 Hz | **4.0** | 每秒闩住多少次新切片 |
| `jump` | Stutter Jump | 0 – 1 | **0.35** | 新切片往缓冲深处跳多远 |
| `mix` | Stutter Mix | 0 – 1 | **1.0** | 干声 ↔ 切片 |

**`jump` 是这台机器上最值得单独拧的旋钮之一**：

- `jump = 0` → 永远闩**最新**的那一段。**最"紧"的重复**，像卡住的 CD。
- `jump = 1` → 可以跳到缓冲深处任意位置。**最"碎"的拼贴**，像在翻找旧录音。

**`rate` 与 `size` 的关系**：`rate` 是"多久换一次"，`size` 是"每次闩多长"。
`rate = 4Hz` + `size = 90ms` → 每 250ms 换一次，每次 90ms——中间有静默。
`rate = 4Hz` + `size = 250ms` → 切片首尾相接，几乎没有原声。

> 切片两端各有 **0.3ms** 的淡化。这不是为了"好听"——硬切在扬声器上会产生
> 很脏的直流冲击，0.3ms 刚好把那个去掉，**但听感上仍然是干脆的断口**，
> 不是被窗函数抹圆的。

### 7.4 ④ COMB — 谐振梳状

**作用**：一条带反馈的短延迟，长度 = `采样率 / tune`。
频谱上形成 `tune` 整数倍处的一排尖峰——于是**噪声也能被听成音高**。

和普通滤波器的区别：它不是在"减"东西，而是在**选出一个音高网格**。

| 短名 | 宿主名 | 范围 | 默认 | 说明 |
|---|---|---|---|---|
| — | **Comb** | 开/关 | **关** | 模块开关 |
| `tune` | Comb Tune | 20 – 4000 Hz | **220** | 谐振基频 |
| `fb` | Comb Feedback | 0 – 0.95 | **0.6** | 反馈量（决定谐振有多"响"、多长） |
| `mix` | Comb Mix | 0 – 1 | **0.5** | 干声 ↔ 谐振 |

**怎么调**：

| `tune` | 听感 |
|---|---|
| **20 – 60 Hz** | 一坨有基音的轰鸣，像低音鼓的余响 |
| **110 – 440 Hz** | 明确的音高，像在弹一个有音高的打击乐器 |
| **1 – 4 kHz** | 尖锐、金属片共振的质感 |

**`fb` 的用法**：`fb` 低（0.2–0.4）是**染色**——加一点金属味。
`fb` 高（0.8+）是**主角**——声音完全变成谐振体。

> **立体声会轻微错开**：右声道延迟比左声道长 **0.8%**，两个梳状网格轻微错开，
> 拍频在声场里来回走。用比例而不是固定样本数错开，因为固定值在高频段会失效。

> 反馈路径上有阻尼低通 + 隔直。所以**高反馈不会自激**，也不会堆直流。

> 实测：`tune` 设 110 / 220 / 440 → 实测 **109.84 / 220.18 / 440.37 Hz**。
> 分数延迟用线性插值，所以低频也调得准（20Hz 时一个样本的误差就是 4% 音高）。

### 7.5 ⑤ TAPE — 磁带变速 / 停转

**作用**：把声音像磁带一样**拉住**——速率从 1 一路拧到 0，音高掉下去，
最后**定死在一个点上**。反向拧过 1 是快进（加速 + 升调）。

| 短名 | 宿主名 | 范围 | 默认 | 说明 |
|---|---|---|---|---|
| — | **Tape** | 开/关 | **关** | 模块开关 |
| `speed` | Tape Speed | 0 – 2.0 × | **1.0** | 读带速率。0 = 停转，1 = 原速，2 = 快进一倍 |
| `wob` | Tape Wobble | 0 – 1 | **0.12** | wow/flutter 抖动深度 |
| `mix` | Tape Mix | 0 – 1 | **1.0** | 干声 ↔ 磁带 |

#### 为什么它听起来像磁带

`speed` 的目标值用 **150ms 一阶平滑**。这一步才是"磁带感"的真正来源：
直接把速率瞬变过去只会听到跳变；平滑之后才是那种**被人用手按住卷轴、
转速慢慢掉下去最后停住**的滑音。

读指针用**线性插值**读，所以音高是连续变化的，不是分段跳的——
这是"磁带"和"采样率压碎"的关键区别。

#### 停转（`speed = 0`）

**它可以无限保持，不会自己复活。**

停转时不只是读头不动——**写头也一起停住**。
如果只停读头、写头照常前进，8 秒后写头会绕回来**覆盖读头正在读的位置**，
停转就自己"复活"了。真磁带停住时读到的是**一段不变的静态磁化**，
模拟它就必须冻结写头。

> 实测：停转 20 秒后末段 RMS 精确为 **0.00000000**。
> （修复前是 0.174——那段"复活"的声音。）

#### 关于"带子会跑完"——这是物理事实，不是 bug

写头以实时速率前进，读头以 `speed` 前进。`speed < 1` 时读头必然越来越落后，
落后的距离就是**磁带存量**。8 秒缓冲就是磁带的总长：

| `speed` | 大约多久用完 |
|---|---|
| 0.5 | 约 16 秒 |
| 0.25 | 约 32 秒 |
| 0 | **永远不会用完**（写头也停了） |

带子用完后读头会被迫回到 1×。为了不出现"速率瞬间从 0.5 跳回 1"的咔哒，
**最后 42ms 做软限位**：速率平滑地滑回 1×，听感上是**磁带被拉紧、自然回到原速**。

#### `wob` 抖动

抖动是**有界的位置偏移**（上限 3ms），不是"乘在速率上"。
最直觉的写法 `pos += speed * (1 + wob)` 会把抖动**积分**成无界的位置漂移，
撞到边界后被夹住，抖动就变成"只往一边摆"。

现在拆成两件事：匀速位置（只有它参与"带子存量"计算）+ 有界抖动偏移。
听感上仍然是完整的 wow/flutter，但位置永远在 ±3ms 内摆动。

> 实测：`speed` 0.25 / 0.5 / 1.0 → **250.00 / 500.00 / 1000.00 Hz** 精确命中。

### 7.6 ⑥ RUIN — 破坏（没有开关）

**作用**：两种人格的**连续渐变**——从干净到彻底破坏。

| 短名 | 宿主名 | 范围 | 默认 | 说明 |
|---|---|---|---|---|
| `mode` | Ruin Mode | 0 – 1 | **0.0** | 0 = **Clear**（干净、可辨识）↔ 1 = **Ruin**（脏、失真、解构） |
| `drive` | Ruin Drive | 0 – 1 | **0.35** | 饱和量 |
| `fold` | Ruin Fold | 0 – 1 | **0.0** | 波形折叠量 |
| `crush` | Ruin Crush | 0 – 1 | **0.0** | 位深压碎 |
| `ring` | Ruin Ring | 0 – 1 | **0.0** | 环形调制深度 |

**`mode` 是连续量而不是开关**，所以从 Clear 拧到 Ruin 是一条**可听的渐变**，
不是硬切。你可以在中间找到"半脏"的位置。

**信号顺序是固定的**：环形调制 → 饱和 → **波形折叠** → 位深压碎。

#### `fold` 值得单独说

饱和（`drive`，tanh）和折叠（`fold`）是**两种完全不同的非线性**：

| | 行为 | 谐波 |
|---|---|---|
| **饱和** | "越推越平"，信号被压成方波 | 增长到一定程度就**停了** |
| **折叠** | "越推越翻"，信号超出 ±1 后被折回来 | **持续爆增**，会自己长出泛音 |

解构音乐里那种"硬"主要来自**折叠**，不是来自失真。

> 实测：折叠的谐波含量 **1.3023**，纯 tanh 饱和只有 0.3754（**3.5 倍**）。

#### `crush` 为什么在 `fold` 之后

先折出谐波，再压位深**把那些谐波糊开**。反过来是先把信号糊了再折，
折出来的东西听不出层次。

#### `ring` 的频率

环形调制的频率**固定 120 Hz**，面板上没有这个旋钮。它不是一个"创作参数"，
是 Ruin 人格的固定成分——就像一台具体设备的固有特性。

---

### 7.7 ⑦ SWEEP — 随机扫频

**作用**：一个截止频率被**随机数**驱动的谐振滤波器。

**为什么是随机而不是 LFO**：LFO 扫频是**有周期感**的，听两小节就记住了，适合做律动。
随机扫频**没有周期**，适合做"这个东西自己在动、你控制不了它"的实验质感。
两者要的东西不一样，这里要的是后者。

| 短名 | 宿主名 | 范围 | 默认 | 说明 |
|---|---|---|---|---|
| — | **Sweep** | 开/关 | **关** | 模块开关 |
| `rate` | Sweep Rate | 0.01 – 20 Hz | **0.8** | 多久抽一个新的目标频率 |
| `cent` | Sweep Center | 60 – 12000 Hz | **1200** | 围绕哪个频率扫 |
| `depth` | Sweep Depth | 0 – 1 | **0.4** | 扫幅。`depth = 1` 时上下各扫 **3 个八度** |
| `reso` | Sweep Reso | 0 – 1 | **0.3** | 共振量（Q 从 0.5 到 12） |
| `mode` | Sweep Mode | **LP / BP / HP** | **LP** | 滤波器类型（单击切档） |

**怎么调**：

- **`rate` 慢（0.05–0.3 Hz）+ `depth` 大** → 很长的呼吸，像风。
- **`rate` 快（8–20 Hz）+ `reso` 高** → 啸叫、尖叫、像无线电干扰。
- **`mode = BP` + `reso` 高** → 电话音 / 老收音机。这是一个非常好用的"降级"效果。

> **扫频在对数域上取值**（±depth×3 个八度），所以听感上是**均匀**的——
> 线性取值会让人觉得"低音区一直在动，高音区几乎不动"。

> **当前频率用一阶低通"滑"向目标**（时间常数 0.4/rate 秒）。
> 直接跳变会咔咔响，滑过去才是"扫"。

> **左右声道共用同一个随机目标**（否则声像会散），但滤波器状态各自独立。

> 滤波器用 TPT 状态变量结构（Zavalishin / Cytomic 那一套）：
> 比双线性变换的直接型**稳定得多**，高频截止不炸，而且 LP/BP/HP 三个输出同源。

### 7.8 ⑧ DELAY — 延迟

**作用**：立体声阻尼延迟，可以 ping-pong。

| 短名 | 宿主名 | 范围 | 默认 | 说明 |
|---|---|---|---|---|
| — | **Delay** | 开/关 | **关** | 模块开关 |
| `time` | Delay Time | 20 – 2000 ms | **375** | 延时时间 |
| `fb` | Delay Feedback | 0 – 0.92 | **0.45** | 反馈量 |
| `damp` | Delay Damp | 0 – 1 | **0.35** | 每次回声的高频衰减 |
| `ping` | Delay PingPong | 0 – 1 | **0.0** | 0 = 普通立体声延迟，1 = 左右来回弹 |
| `mix` | Delay Mix | 0 – 1 | **0.35** | 干声 ↔ 延迟 |

**三个让它听起来不像"数字延迟"的细节**（都是固定的，面板上没有旋钮）：

1. **延时时间不是硬切**，而是用 50ms 一阶滑过去——拧 `time` 会像老磁带一样滑音。
2. **读位置叠了一层极轻的固定调制**（0.15ms @ 0.25Hz）。静态数字延迟在长反馈下
   会有**金属鸣响**（因为所有回声的相位关系永远不变），轻微抖动就把它化开了。
3. **反馈路径里带阻尼低通 + 隔直**。没有隔直的话，反馈环会把直流慢慢堆起来，
   长尾最后变成一段偏移而不是声音。

`time = 375ms` 是出厂值，对应 160 BPM 的 1/4 音符。**但它不跟随 BPM**——
要跟拍就自己拧。

---

### 7.9 ⑨ SPACE — 巨大空间（没有开关）

**作用**：一块**非常大**的板式混响。

拓扑是经典的 Schroeder/Freeverb 结构（8 个并联梳状滤波器 + 4 级串联全通），
但做了两处针对"非常大"的改动：

1. **梳状延迟线可放大到 2.5 倍**（最长约 92ms），配合高反馈得到**十几秒的尾音**。
2. **每条梳状延迟加低频调制**——不加的话长尾会变成明显的**金属鸣响**。

| 短名 | 宿主名 | 范围 | 默认 | 说明 |
|---|---|---|---|---|
| `mix` | Space Mix | 0 – 1 | **0.55** | 干声 ↔ 混响 |
| `size` | Space Size | 0 – 1 | **0.7** | 空间尺寸（放大延迟线） |
| `tail` | Space Tail | 0 – 1 | **0.8** | 尾音长度（梳状反馈） |
| `damp` | Space Damp | 0 – 1 | **0.4** | 高频衰减 |
| `diff` | Space Diffuse | 0 – 1 | **0.7** | 扩散（全通反馈） |

**怎么调**：

- **`size` 大 + `tail` 大 + `damp` 高** → 大教堂 / 深渊。`damp` 高是关键，
  否则长尾会刺耳。
- **`size` 小 + `diff` 低** → 小房间 / 弹簧混响的粗糙感。
- **`tail` 拉满** → 十几秒的尾音，适合做"声音散开"的收尾。

> **`modDepth` 固定 0.3，面板上没有。** 它是"消除金属鸣响"的机制，不是创作参数。

> **这个模块没有开关**，出厂就在工作（`mix = 0.55`）。要完全干净就把 `mix` 拧到 0。

### 7.10 ⑩ OUT — 输出（没有开关）

| `level` | Output | −24 – +12 dB | **0.0** | 输出增益 |

让限制器压得更多。想要整体更响，用后面的限制器余量去换（见下一章）。

## 八、输出与限制器

信号链的最后是一个**前瞻式峰值限制器**。它**总是开着**，没有开关。

### 8.1 为什么必须有前瞻

反馈式限制器（先量峰值、再降增益）对瞬态**无能为力**——
峰值到达那一刻，包络才刚开始往上爬，增益还是 1.0，于是**必然过冲**。

> 实测证据：阈值 0.95、起控 1ms 的反馈式限制器，在 +4.8 dB 输出增益下
> 峰值冲到 **1.0062**（越界 0.6%）。

现在的做法：把信号延迟 L 个样本再输出，而增益由**还没延迟的**样本（也就是未来）决定。
于是峰值真正到达输出端时，增益早已降到位——**数学上不可能过冲**。

**压降立即生效**（保证不过冲），**恢复缓慢**（150ms，避免抽吸感）。

### 8.2 延迟：2ms

前瞻会引入 **2ms 的固定延迟**。插件已经通过 `setLatencySamples()` 报告给宿主，
**DAW 会自动补偿**，你不需要做任何事。

> **如果你同时挂多个实例**：每个实例各报 2ms，宿主会各自补偿，总延迟不变。

> **旁通时也会延迟。** 这是有意的——旁通状态下延迟量与正常处理时一致，
> 宿主的补偿才对得上。否则一开一关，别的轨道就会**突然错位 2ms**。

### 8.3 电平策略

- 想要**整体更响**：先拧 `OUT` 的 `level` 往上推，让限制器接住峰值。
- 想要**完全干净**：把 `level` 保持在 0 dB 附近，别推。
- **输出峰值不会超过 0 dBFS**，不会削顶。

## 九、面板背景图（可选）

顶栏左边那一格 `CHOOSE IMAGE` 可以给你自己的面板换一张背景图。

### 怎么用

1. 点 **`CHOOSE IMAGE`** → 选一张图。
   支持 `png / jpg / jpeg / gif / bmp / webp / tiff`。
2. 选完它会自动切到 **`FULL`**（铺满参数区）——选了图就该看得见。
3. **`OFF` / `FULL`** 两格控制显示 / 隐藏。
4. 右边的**明暗度轨道**调亮度，范围 **0.25× – 4.0×**（几何级数）。
   刻度在 1.0× 处。**点哪儿跳哪儿**，也可以拖。有图没图都能调。

### 几个细节

- 背景图铺在**参数区**下面（不是整块面板），四边有 **64px 羽化**。
- 明暗度的峰值是经过校准的：**压在最亮的背景上，白字仍然有 5.97:1 的对比度**。
  所以你把亮度推到 4.0× 也不会看不清参数名。
- **图片不会被存进工程文件。** 工程里存的是**路径 + 落位 + 明暗度**。
  把工程拷到另一台机器，如果那张图不在同一个路径，背景就是空的（参数不受影响）。

## 十、实用配方

### 配方 1：硬边切片填充（最常用）

**目标**：在一段音乐里制造"卡住了"的填充。

1. `STUTTER` 开。
2. `rate` 拧到 **8–16 Hz**，`size` 拧到 **30–60 ms**。
3. `jump` 慢慢往上拧，找到那个"翻找旧录音"的感觉。
4. 把 `STUTTER` 关掉再打开，做成一瞬间的动作。

> 想更狠：`STUTTER` 后面接 `COMB`（`tune` 300–600 Hz，`fb` 0.7）。
> 切片会被染上音高，听起来像一台坏掉的机器在敲。

---

### 配方 2：磁带停转（收尾 / 过门）

**目标**：让音乐"漏气"一样慢下来。

1. `TAPE` 开。
2. 把 `speed` 从 1.0 慢慢拧到 **0**（或者用 DAW 的自动化曲线画下去）。
3. 想让停转更有质感：`wob` 拧到 **0.3–0.5**，停转时会带一点晃动。
4. 想接回去：把 `speed` 拧回 1.0。**不会咔哒**——软限位会平滑接上。

> **接在 COMB 后面效果最好**：谐振会跟着一起掉下去，像真的磁带机断电。

---

### 配方 3：冻结音墙

**目标**：把一瞬间的声音变成一片持续几分钟的墙。

1. 放一段**密集的**素材（鼓组、噪声、人声堆叠）。
2. `FREEZE` 开。
3. `loop` 拧到 **30–80 ms**——很短的循环，听起来像一个持续音。
4. `seam` 拧到 **20–30 ms**（循环短的时候接缝更明显，淡化要长一点）。
5. 接 `SPACE`：`size` 0.9、`tail` 0.95、`damp` 0.5。得到一片十几秒的尾音。

---

### 配方 4：谐振金属染色

**目标**：让素材听起来像金属 / 玻璃 / 塑料。

1. `COMB` 开，`tune` 拧到 **800–2500 Hz**，`fb` **0.75–0.9**。
2. `mix` 拧到 **0.4–0.6**（不要 1.0，保留原声的辨识度）。
3. 接 `RUIN`：`fold` 拧到 **0.3–0.5**。折叠会把谐振的谐波炸开，金属感立刻出来。

---

### 配方 5：波形折叠破坏（最"解构"的一招）

**目标**：把素材变成完全不可辨认的东西。

1. `RUIN` 的 `drive` 拧到 **0.6**（先推到接近方波）。
2. `fold` 慢慢往上拧到 **0.5–0.8**。你会听到**新的泛音自己长出来**。
3. `crush` 拧到 **0.3–0.5**——把那些谐波糊开。
4. `ring` 拧到 **0.2–0.4** 加一点金属的环形调制味。
5. `mode` 拧到 **1.0**（Ruin 人格）让整个链路的染色更彻底。

> 顺序别反：`fold` 在前、`crush` 在后是**固定**的。
> 先折出谐波、再压位深糊开，才有层次。

---

### 配方 6：随机扫频做"它在动"

**目标**：给一个静止的声音加上"不可预测的呼吸"。

1. `SWEEP` 开。
2. `rate` 拧到 **0.05–0.2 Hz**（很慢），`depth` 拧到 **0.8–1.0**。
3. `cent` 拧到 **800–2000 Hz**，`reso` 拧到 **0.5–0.7**。
4. `mode` 用 **BP** 更明显，**LP** 更含蓄。

> 想要"干扰"感：`rate` 拧到 **10–20 Hz**，`reso` 拧到 **0.9**，
> `mode` 用 **BP**。听起来像无线电被干扰。

---

### 配方 7：完全干净的"直通"

**目标**：确认插件什么都没做（用于对比）。

1. `Space Mix` → **0**
2. `Ruin Drive` → **0**，`Ruin Mode` → **0**
3. 七个模块开关全部**关**
4. `Output` → **0 dB**

此时只有 2ms 延迟 + 限制器在工作（限制器不压缩，因为没超阈值）。

## 十一、常见问题与排错

### Q：装了插件，DAW 里找不到

1. **确认装到了哪里**：
   ```bash
   ls -la ~/Library/Audio/Plug-Ins/VST3/Trane.vst3
   ls -la ~/Library/Audio/Plug-Ins/Components/Trane.component
   ```
2. **让 DAW 重新扫描**（见 [2.4](#24-在-daw-里让它出现)）。
3. **检查有没有旧版本残留在系统级目录**：
   ```bash
   ls -la /Library/Audio/Plug-Ins/VST3/Trane.vst3
   ls -la /Library/Audio/Plug-Ins/Components/Trane.component
   ```
   有的话删掉——两份并存、版本不一致是最难查的一类问题。
4. **Ableton 用户**：设置里「使用 VST3 系统文件夹」之类的开关，
   关掉再打开，强制它重扫。

---

### Q：装了新版，界面还是旧的

**99% 是两份并存。** 按上面第 3 步查系统级目录。

如果两边都只有一份，那可能是 DAW 缓存了插件信息——重启 DAW。

**验证你装的是哪一版**：面板上**不显示版本号**（这是有意的设计——
面板上不该有非交互文字）。要确认版本，直接问插件包自己：

```bash
# VST3
/usr/libexec/PlistBuddy -c "Print :CFBundleShortVersionString" \
  ~/Library/Audio/Plug-Ins/VST3/Trane.vst3/Contents/Info.plist

# AU
/usr/libexec/PlistBuddy -c "Print :CFBundleShortVersionString" \
  ~/Library/Audio/Plug-Ins/Components/Trane.component/Contents/Info.plist
```

v0.36 会打印 `0.36`。

想再确认一次**素材**真的打进去了（不只是版本号对）：

```bash
strings -a ~/Library/Audio/Plug-Ins/VST3/Trane.vst3/Contents/MacOS/Trane | grep TRNL
```

有输出就说明这个二进制里带着品牌标素材（`TRNL` 是它的容器标识，v0.36 起才有）。

---

### Q：声音一直在响，关掉插件也没用

**`FREEZE` 还开着。** 冻结会**无限保持**——这是它的设计目标。
点一下 `FREEZE` 的标题行关掉它。

如果关掉 `FREEZE` 还在响，检查 `DELAY` 的 `fb` 是不是拉得太高（长尾）。

---

### Q：磁带停转之后，过一会儿自己又有声音了

**这是设计内的行为，而且是可以解释的**：磁带存量用完了，软限位把速率拉回 1×。

- 想让它**永远停住**：`speed` 拧到 **正好 0**。这时写头也会停，可以无限保持。
- `speed` 在 **0.01–0.1** 之间：带子会慢慢用完（几十秒到几分钟）。

> 如果你在 `speed = 0` 时**还**听到它复活，那是 bug，请报告。

---

### Q：`FREEZE` 打开时听到咔哒

把 `seam` 调大。短循环（`loop` < 100ms）需要更长的接缝淡化。

`seam = 0` 是**故意允许**咔哒的——某些 Ruin 用法里那个咔哒本身就是素材。

---

### Q：参数拖不动 / 拖了没反应

- **连续参数单击不改值**，这是防手抖的设计。要拖。
- 检查是不是点在了**模块标题行**上——标题行是开关，不是参数。
- **关闭的模块**参数**照样能拖**（这是有意的），但它的视觉效果是压暗的。

---

### Q：模块标题点不开 / 点不动

- **RUIN / SPACE / OUT 的标题行本来就点不动**——它们没有开关。
- 其他模块如果点不动，检查是不是在**拖动**（拖超过 2 像素就变成拖拽，不触发单击）。

---

### Q：双击之后参数变了两次

**这是 JUCE 的事件顺序决定的，不是 bug。**

一次双击会送出：按下1 · 松手1 · 按下2 · 松手2 · 双击。
所以**松手动作不会被抑制**。设计上让单击动作满足"**做两遍 = 没做**"：

| 控件 | 两次单击的净效果 |
|---|---|
| 模块开关 | 关 → 开 → **复位（默认关）= 关** ✓ |
| 档位参数（LP/BP/HP） | 走两档再复位到 LP ✓ |
| 连续参数 | 单击本来就不改值 ✓ |

代价是中间闪一下。这比"把单击动作延后 250ms 再执行"好得多——
后者会让每次点模块开关都发钝。

**唯一被挡住的**是「选择图片」（连开两次系统对话框显然不合理）。

---

### Q：面板上的文字有点小 / 糊

面板是 1440×720。如果你的显示器是 4K，窗口会按比例缩放。
把 DAW 的插件窗口**拉大**（上限 150%）或者**拉小**（下限 60%）。

下限 60% 是因为参数名是 11pt，0.60 下只有 6.6 逻辑像素——再小就糊成一团。

---

### Q：延迟补偿之后还是对不上

**检查旁通状态**。旁通时插件**仍然报 2ms 延迟**（有意设计，保证开关一致）。
如果你的 DAW 在旁通时忽略延迟报告，那会出现 2ms 错位——这是 DAW 的行为，不是插件。

---

### Q：能不能用 MIDI 控制

当前版本**不支持 MIDI 映射**。但所有参数都在 DAW 的自动化列表里，
可以用 DAW 自己的 MIDI 映射功能（Ableton 的 MIDI Map、Logic 的 Smart Controls 等）。

---

## 附：这台机器是怎么被验证的

这一节不是使用说明的一部分，但如果你想知道"这些数字凭什么可信"，可以看。

Träne 的 DSP 核心**刻意不依赖 JUCE**，可以脱离宿主独立编译、离线渲染。
于是每个结论都可以用**测量**得到，而不是靠"开 DAW 听"：

- **门禁**：`cd vst && ./run_tests.sh` —— 构建 → 127 项 pytest → 六组反向对照
  → 端到端（把真实 `.vst3` 加载起来渲染音频）。
- **反向对照（变异测试）**：故意把源码改坏、重编、确认检查器**真的报红**。
  绿本身不是证据——一个永远绿的检查器什么都没检查。
  六组对照共 **34 处突变**，全部被抓到。
- **端到端**：把编译出来的 `.vst3` 当插件加载、通过 VST3 参数接口设参数、
  渲染音频、分析结果。它证明的是"**这个文件能装进 DAW 干活**"，
  而不只是"算法写对了"。

**本章所有实测数字都来自离线段探针，每个都有对照组。**
